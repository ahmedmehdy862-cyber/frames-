لوحة التحكم تحتاج ربطاً بالخادم

لتأمين اللوحة بحسابات حقيقية، اربط الموقع بمشروع Supabase مجاني:

  1. أنشئ مشروعاً على supabase.com ثم شغّل ملف supabase/schema.sql في SQL Editor.
  2. انسخ Project URL وanon key من Project Settings → API إلى الملف js/config.js.
  3. أنشئ حساب المالك وانشر دالة admin-users (الخطوات كاملة في SETUP-AR.md).

حتى ذلك الحين، لا يتوفر دخول إلى اللوحة، ويعمل الموقع العام من config/frames.json.
